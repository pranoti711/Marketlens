• Derived KPI fields where they represent meaningful business metrics.

CALCULATE IN POWER BI WHEN POSSIBLE:
• CTR = Total Clicks / Total Impressions
• CPC = Total Spend / Total Clicks
• CPA = Total Spend / Total Conversions
• ROAS = Total Revenue / Total Spend

WHY:
Aggregated ratios should generally be calculated from aggregated numerators and denominators rather than averaged from row-level ratios.

QA / HIDDEN FROM MAIN DASHBOARD:
• Validation difference fields
• Validation flags
• IQR outlier flags
• Negative-value flags
• Duplicate flags
• Missing-value flags

DO NOT USE AS ANALYTICAL FEATURES:
• Marketing A/B 'Unnamed: 0' index metadata

IDENTIFIER FIELDS:
Use IDs for traceability or DISTINCTCOUNT where appropriate; do not sum identifier values.

====================================================================================================
DATA QUALITY AND CLEANING PRINCIPLES
====================================================================================================

1. RAW DATA PRESERVATION
The original CSV files in data/raw are preserved unchanged.

2. CLEANED DATA LAYER
The data/cleaned directory contains one cleaned dataset per source dataset. Analytical and quality fields were added without deleting the original source columns.

3. OUTLIER HANDLING
Outliers are identified using the IQR rule and flagged for investigation. They are not automatically removed because statistical unusualness does not necessarily indicate invalid data.

4. KPI VALIDATION
Reported advertising KPIs are independently recalculated where mathematically possible. Validation differences and flags are retained for transparency.

5. DIVISION-BY-ZERO HANDLING
Calculated ratios with a zero denominator are represented as missing analytical values rather than being incorrectly forced to zero.

6. SOURCE-DEFINITION ANOMALIES
The KAG dataset contains records where Total_Conversion exceeds Clicks. These records are retained and explicitly flagged because the exact source metric definition is not independently established.

7. TRACEABILITY
Source fields are retained in the cleaned datasets so that calculated metrics and analytical transformations can be traced back to the original observations.
